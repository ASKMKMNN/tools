# 录屏批量压缩 v1.2

把 Win+G 录的竖版/大尺寸录屏，批量居中裁成 16:9 → 缩到 1080p → 压体积 → 音量标准化。
**单文件 bat**，复制到视频所在文件夹双击即用；v1.2 起会先弹深色选项窗口（右上角可切浅色）。

## 下载

- [录屏批量压缩.zip](录屏批量压缩.zip) —— 推荐，内含脚本 + 完整说明 + 本页
- 只要脚本：[compress_mp4_v1.2.bat](compress_mp4_v1.2.bat)
- 完整备忘：[使用说明_v1.2.md](使用说明_v1.2.md)

## 怎么用

1. 本机装好 [FFmpeg](https://www.gyan.dev/ffmpeg/builds/)（或把 `ffmpeg.exe` 放到脚本同目录）
2. 把 `compress_mp4_v1.2.bat` 放到**视频所在的那一层文件夹**
3. 双击 → 选好 4 组选项 → 点「开始压缩」
4. 成品在同目录 `compressed\`，文件名不变，**原文件不动**；已存在的成品自动跳过

## 4 组选项（加粗 = 默认值，与 v1.0 行为一致）

| 组 | 选项 |
|---|---|
| 画面裁切 | 不变 / **16:9 居中剪裁** |
| 输出分辨率 | 沿用 / **1080P** / 720P |
| 音频 | 沿用（直接复制原音轨）/ **标准化 -16 LUFS** |
| 颜色 / 像素格式 | 沿用 / **yuv420p** / 其它 5 种 |

固定参数：libx264 / CRF 28 / veryfast / 30fps / +faststart。
点「取消」或关窗口不处理任何文件；没有 PowerShell 时自动降级成文字菜单。

## 注意

- `compress_mp4_v1.2.bat` **必须保持 GBK(ANSI) 编码、无 BOM、CRLF**，存成 UTF-8 会让窗口中文乱码
- 仅处理当前目录下的 `.mp4`
- 脚本用自身路径 `%~f0`，文件名可随意改，不影响运行
- 4:2:2 / 4:4:4 / 10bit 在微信、浏览器、手机、QuickTime 上可能放不了，日常保持 yuv420p
