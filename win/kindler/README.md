# 📖 Kindle 局域网一键传书工具 (Kindler) 部署与使用指南

## 📌 项目背景与初衷
- **痛点**：亚马逊中国区服务退出，使用美区账号进行“邮箱推送”跨国延迟极高；使用 Calibre 开启内容服务器时，因本机存在虚拟网卡（代理软件/虚拟机）及防火墙设置，导致 Kindle 无法连接。
- **目标**：寻找一个轻量级、不越狱、不走外网、完全依赖家庭局域网的本地传书方案。
- **最终方案**：采用基于 Node.js 的开源小工具 **Kindler**，并通过自定义批处理脚本（`.bat`）实现**一键启动、自动识别真实 IP、自动打开浏览器**的丝滑体验。

---

## ⚙️ 环境准备（仅需配置一次）
1.  **安装 Node.js**：前往[官网](https://nodejs.org/)下载 LTS 版本（Windows `.msi` 安装包），一路 `Next` 安装。（*注意：安装时不需要勾选 Python 和 Visual Studio 编译工具*）。
2.  **获取源码**：下载 Kindler 源码包并解压，确保文件夹内包含 `server.js` 和 `package.json`。
3.  **安装依赖**：
    *   在 Kindler 文件夹的地址栏输入 `cmd` 回车。
    *   输入 `npm install` 并回车，等待依赖包下载完成。（*如果提示路径错误，请使用 `cd /d "你的文件夹绝对路径"` 切换后再执行*）。

## 🚀 核心资产：一键启动脚本 (`.bat`)
在 Kindler 文件夹中新建一个文本文档，复制以下代码，另存为 **`启动传书.bat`**（编码选择 ANSI，或直接使用代码中的 `chcp 65001` 防乱码）。

```bat
@echo off
chcp 65001 >nul
title Kindle 一键传书
color 0B
echo ===================================================
echo       正在检测当前电脑的局域网 IP 地址...
echo ===================================================
echo.

:: 自动提取真实的 192.168 开头的 IPv4 地址（避开虚拟网卡）
for /f "delims=" %%a in ('powershell -NoProfile -Command "Get-NetIPAddress -AddressFamily IPv4 | Where-Object {$_.IPAddress -like '192.168.*'} | Select-Object -First 1 -ExpandProperty IPAddress"') do set "LOCAL_IP=%%a"

if defined LOCAL_IP (
    echo  [提示] 请在 Kindle 浏览器中，输入以下网址：
    echo.
    echo       http://%LOCAL_IP%:3000
    echo.
) else (
    echo  [注意] 没找到 192.168 开头的局域网 IP，请检查电脑是否连上了 Wi-Fi。
)

echo ===================================================
echo.
echo  ▶ 正在启动传书服务...
echo  ▶ 3秒后将自动为你打开电脑浏览器...
echo.
echo  [注意] 请不要关闭这个黑框框！关了服务就停了！
echo.

:: 倒计时3秒，让你看清上面的IP地址
timeout /t 3 /nobreak >nul

:: 自动打开电脑上的浏览器
start http://localhost:3000

:: 在当前窗口启动服务
node server.js
```

## 📚 日常使用三步走
1.  **启动服务**：双击 `启动传书.bat`，此时会弹出一个蓝色字体的黑框窗口，**请不要关闭它**。
2.  **电脑上传**：电脑浏览器会自动弹出传书网页（`http://localhost:3000`），将电子书（推荐 AZW3 格式）拖拽进去并点击 Upload。
3.  **Kindle 下载**：
    *   确保 Kindle 与电脑连接**同一个家庭 Wi-Fi**。
    *   打开 Kindle 浏览器，输入黑框里显示的局域网地址（如 `http://192.168.0.102:3000`）。
    *   点击书名即可直接下载。传完书后，关闭电脑上的黑框即可结束服务。

## 🚨 避坑与排错速查（血泪经验）

- **🛑 IP 地址陷阱（最容易踩坑）**
    *   **绝对不要用** `172.30.x.x` 或 `10.x.x.x` 的地址，那是代理软件（Clash等）或虚拟机生成的**虚拟网卡**，Kindle 根本连不上。
    *   本脚本已强制过滤，只抓取真实的 `192.168.x.x`。如果脚本没抓到，请按 `Win+R` 输入 `cmd`，输入 `ipconfig`，找到“无线局域网适配器 WLAN”下的 IPv4 地址。
- **🛑 Kindle 浏览器输入规范**
    *   必须完整输入 `http://` 打头，否则 Kindle 浏览器可能会自动补全为 `https://` 导致连接失败，或者直接跳转去百度搜索。
- **🛑 防火墙拦截**
    *   如果 Kindle 打不开网页，检查 Windows 防火墙：在“允许应用通过防火墙”中，把**所有**带有 `Node.js` 字样的条目，后面的“专用”和“公用”全部打勾。
- **🛑 文件命名**
    *   尽量避免使用纯中文命名电子书，部分老版本 Kindle 浏览器在下载中文名文件时会卡住或乱码，建议重命名为英文或拼音。
- **❓ 为什么不推荐 Calibre 传书？**
    *   本机网络环境复杂（有虚拟网卡），Calibre 的内容服务器端口（默认8080）和局域网权限绑定机制极其繁琐，容易受防火墙和代理软件干扰。Kindler 轻量且直连，更为稳定。

## 📦 终极备份建议
请将配置好的整个 **`kindler_v1.0.0` 文件夹**（包含 `node_modules` 依赖包和 `启动传书.bat`）打包成 ZIP 压缩包，存入网盘或 U 盘。以后换电脑或重装系统，只需安装 Node.js，解压该文件夹，双击 BAT 即可满血复活。
