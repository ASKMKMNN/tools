Kindler 局域网传书

一台电脑、同一个 Wi-Fi，把电子书直接送进 Kindle。不走邮箱推送、不用数据线，也不经过外网。准备好下面几样就能用。

需要准备

  • Node.js LTS：官网下载，Windows 选 .msi，一路 Next 即可。
  • Kindler 本体：去官方仓库，下载源码 zip，或下仓库里那份现成打包 zip。解压后目录里要有 server.js 和 package.json。
  • 依赖包：在解压出来的文件夹地址栏输 cmd 回车，跑一次 npm install。第一次要联网，之后不用管；两个 zip 都不含 node_modules。
  • Calibre（可选）：官网下载。只有要用网页里的「转换成 AZW3」按钮时才装，直接传 AZW3 可以跳过。
  • 电子书：自备，推荐 AZW3，文件名尽量用英文或拼音。

一键启动

把 启动传书.bat 放进 Kindler 文件夹，双击。黑框会显示 http://192.168.x.x:3000；电脑浏览器自动打开上传页，Kindle 浏览器输黑框里的地址就能下书。传完关掉黑框才结束服务，中途别关。
