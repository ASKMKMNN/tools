# 书影游助手（Android 版）

网页版已停止使用，这里只放 Android 安装包 `shuyingyou-v13.apk`，版本 1.12（构建 v13）。此版只更新桌面启动图标（缩到自适应遮罩安全区内），业务功能与上一版一致，同一把密钥签名，可直接覆盖安装。

## 怎么用

打开下面的入口页，点「下载 Android 安装包」；下载完点开 APK，系统若提示未知来源就允许这一次，装好从桌面图标打开。之前装过旧版可以直接覆盖安装，签名相同，已记的条目不会丢。

## 依赖

Android 手机即可，浏览器只用来下载。不需要账号、不需要密钥，记录只存在本机。

## 脱敏说明

APK 不含密钥、本机路径、个人片单或片单标题；新装打开时库是空的。目录里剩下的 `covers/`、`manifest.webmanifest`、`tests/` 是旧网页版的遗留文件，页面已不再引用，不作为可安装 PWA 提供。
