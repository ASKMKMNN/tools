# 书影游助手

在这台设备上记录书、动漫、剧集、电影和游戏：想看、在看、已看（书是读，游戏是玩）。进度记在浏览器里，断网也能改。

## 怎么用

用浏览器打开下面的入口。可以「安装」或「添加到主屏幕」，之后从图标打开。右下角 ＋ 添加一条。资料可查 Bangumi；书还可以查 Open Library。电影和剧的 TMDB、图片识别要自己填密钥，不填就保持关闭，可以手动记。

从追番助手导入后，手机里的 `file://` / `content://` 封面在网页里打不开。有 Bangumi 编号的，用设置里的「刷新已绑定的 Bangumi」重取网络图（不改已记下的进度）；没有编号的，用「逐条补封面」查资料绑定或手动粘贴图片地址。封面加载失败时卡片上会出现「点此补图」，不会静默消失。

已装到主屏的旧版本会在打开时自动换到新版并重新载入一次，不需要清除站点数据或卸载重装。

## 依赖

现代浏览器即可。没有预置密钥，也不需要注册本工具的账号。Bangumi 和 Open Library 查询不需要密钥。TMDB 和图片识别需要你自己的密钥；浏览器若拦截跨域，页面会说明失败原因。本工具不带代理服务器，也不会后台提醒。

## 脱敏说明

本包不含密钥、不含个人片单、不含本机路径。打开后库是空的。密钥只在你选择「记住在这台设备」时写入本站点的 localStorage，不会进导出文件。旧的追番助手备份可以导入，本机记录仍用原来的存储键。
