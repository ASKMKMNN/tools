# 小工具

两个可以单独安装的网页工具，放在 GitHub Pages 上。每个工具只缓存自己目录里的文件，安装之后互不影响，断网也能打开。

## 网址

- 导航页：<https://askmkmnn.github.io/tools/>
- 周期频率换算器：<https://askmkmnn.github.io/tools/freq/>
- 省钱比价：<https://askmkmnn.github.io/tools/price/>

请先打开要安装的那个工具页面，再按下面的步骤操作。导航页本身不能安装。两个工具需要各装一次。

## 在安卓上安装

用 Chrome 打开上面的工具网址：

1. 如果地址栏或页面底部出现「安装」，直接点它。
2. 否则点右上角菜单（⋮），选择「安装应用」或「添加到主屏幕」。
3. 确认之后，主屏幕会出现这个工具的图标。以后从图标打开，没有网络也可以用。

## 在 iPhone / iPad 上安装

请用 Safari 打开工具网址。从别的浏览器进来时，先选「在 Safari 中打开」。

1. 点底部分享按钮（方框加向上的箭头）。
2. 往下找到「添加到主屏幕」。
3. 名称保持默认即可，点右上角「添加」。

iPhone 和 iPad 不会弹出自动安装条，需要按上面的步骤手动添加。添加后，主屏幕图标会像普通 App 一样打开，断网也能用。

## 在电脑上安装

用 Chrome 或 Edge 打开工具网址：

1. 地址栏右侧出现安装图标（显示器加向下箭头）时，点它。
2. Chrome 也可以打开右上角菜单，选择「安装周期频率换算器」或「安装省钱比价」。
3. Edge 可以打开菜单里的「应用」，再选「将此站点作为应用安装」。
4. 确认安装。之后可以从开始菜单、启动台或桌面图标打开，断网也能用。

第一次需要联网打开一次，浏览器会把这个工具的页面和图标缓存下来。
