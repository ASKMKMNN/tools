# 信息流

## 是什么

自用 RSS 信息流。可以订阅源、按分组整理、收藏文章，已经抓到的内容断网也能看。

内置一套默认订阅，首次打开会自动加载。默认筛选条顺序是「新闻+、设计、杂志、图流、信息流、科技、全部」。最左侧分组即打开时的默认页，可在管理分组里调整顺序。默认「推荐」已拆成「图流」和「信息流」两个分组；已不再内置 IT之家。

顶部可以切到「图流」页面。图流只显示大图，小图、图标和横幅会滤掉。过滤强度在「订阅与设置」里选「严」或「中」。

## 怎么用

打开 <https://askmkmnn.github.io/tools/rss/>。

安卓用 Chrome：地址栏或菜单里选「安装」或「添加到主屏幕」。iPhone / iPad 用 Safari 打开，点分享，选「添加到主屏幕」。装好后从图标进入。

点右上角「订阅与设置」（≡）：最前面是「添加订阅」，也可新建分组、批量移动订阅源，或导入 OPML。在订阅列表点「批量移动」，勾选多个源后可一次移到已有分组、未分组，或新建分组。默认使用作者自建的 Cloudflare Worker 代理（仅允许本站来源调用），设置里可改。

从后台回到前台时，如果超过 15 分钟没刷新，会自动刷新一次（冷启动同样是 15 分钟）。信息流和图流显示完全部条目后，底部会提示「已经到底了」和上次刷新时间，可点旁边的刷新按钮；收藏页只显示提示、不带刷新按钮。

## 数据存在哪与备份

数据只在这台设备的浏览器里。订阅、分组和设置在 localStorage，文章在 IndexedDB。换手机或清除站点数据之前先备份。

在「订阅与设置」里：

- 导入 OPML、导出 OPML：订阅列表，分组一起带走。
- 备份 JSON、从 JSON 恢复：订阅、分组、筛选条顺序、收藏的文章和设置。文章列表本身恢复后会重新抓。

## 已知限制

部分源可能抓不到。代理清单可以在「订阅与设置」里改。自建代理留空后，会再试直连和公共代理。
