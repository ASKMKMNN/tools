# 信息流

版本 **v1.13**（2026-11-13）。对外版本一律用 v1.x（不超过 v2）。旧版 v1–v10 对应 v1.1–v1.10（其中 v6.1 记为 v1.6.1）。

## 是什么

自用 RSS 信息流。可以订阅源、按分组整理、收藏文章，已经抓到的内容断网也能看。

内置一套默认订阅，首次打开会自动加载。默认筛选条顺序是「新闻+、设计、杂志、科技、图集推荐、新闻推荐、全部」，其中「全部」默认不显示。最左侧还能看见的分组即打开时的默认页，可在管理分组里调整顺序。默认「推荐」已拆成「图集推荐」和「新闻推荐」两个分组（旧名「图流」「信息流」）；已不再内置 IT之家。

每个分组只以一种方式显示：信息流、图流，或不显示（该分组从分组栏隐藏）。默认「杂志、设计、图集推荐」用图流，其余（新闻+、新闻推荐、科技、未分组等）用信息流。「全部」默认从筛选条隐藏，聚合功能还在；在分组设置里可以改成信息流、图流或不显示。重新打开后按原来的位置出现，并记住，之后不会再自动隐藏。右上角按钮可把当前分组在信息流和图流之间切换，立刻生效并保存到设置。加减列按钮只在当前分组是图流时出现。

图流只显示大图，小图、图标和横幅会滤掉。过滤强度在「订阅与设置」里选「严」或「中」。

## 怎么用

打开 <https://askmkmnn.github.io/tools/rss/>。

安卓用 Chrome：地址栏或菜单里选「安装」或「添加到主屏幕」。iPhone / iPad 用 Safari 打开，点分享，选「添加到主屏幕」。装好后从图标进入。

点右上角「订阅与设置」（≡），顶部可在「订阅 / 分组 / 其他」三个标签之间切换，会记住你上次打开的标签。「订阅」里可添加订阅、批量移动，以及查看订阅列表（篇数和代理显示在网址下一行）。「分组」里管理分组顺序、改名、删除，以及每个分组的显示方式（信息流 / 图流 / 不显示）。「全部」也在这里，默认是不显示，改成信息流或图流就会回到筛选条。如果一个分组都看不见，主页面会给出空状态和「分组设置」入口，不会把「全部」强行加回来。「其他」里是当前版本和更新记录、显示、缩略图、代理，以及 OPML / JSON 备份导入导出。默认使用作者自建的 Cloudflare Worker 代理（仅允许本站来源调用），设置里可改。

点筛选条上的某个分组会立刻刷新这一组的源（「全部」刷全部，收藏不刷），先显示已缓存的内容，顶部出现细进度条。同一分组 60 秒内不会重复刷；连点切换分组时，过期的刷新结果会被忽略。

从后台回到前台时，如果超过 15 分钟没刷新，会自动刷新一次（冷启动同样是 15 分钟）。信息流和图流显示完全部条目后，底部会提示「已经到底了」和上次刷新时间，可点旁边的刷新按钮；收藏页只显示提示、不带刷新按钮。某个分组没有图或文章时，会显示「这个分组暂时没有图/文章」和刷新按钮，不会出现没有提示的整屏空白。

## 数据存在哪与备份

数据只在这台设备的浏览器里。订阅、分组和设置在 localStorage，文章在 IndexedDB。换手机或清除站点数据之前先备份。

在「订阅与设置」里：

- 导入 OPML、导出 OPML：订阅列表，分组一起带走。
- 备份 JSON、从 JSON 恢复：订阅、分组、筛选条顺序、收藏的文章和设置。文章列表本身恢复后会重新抓。旧备份里每个分组的「在信息流显示 / 在图流显示」两个开关，会按规则转成新的显示方式。仍叫「图流」「信息流」的分组会改名为「图集推荐」「新闻推荐」；若「科技」和「图集推荐」都在，会把「科技」挪到「图集推荐」前面。还没记过「全部已隐藏」的备份，恢复时会把「全部」从筛选条隐藏一次；已经重新打开并备份过的，会保持打开。

## 已知限制

部分源可能抓不到。代理清单可以在「订阅与设置」里改。自建代理留空后，会再试直连和公共代理。
